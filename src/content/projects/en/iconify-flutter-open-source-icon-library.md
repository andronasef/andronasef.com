## Project Overview

Iconify Flutter is an open source package I created that brings the huge [Iconify](https://iconify.design) ecosystem to Flutter. Instead of hunting for one icon font after another, developers get 100+ open source icon sets — thousands of icons — behind a single, consistent widget.

The package has passed **8K+ downloads in the last 30 days** and **471 likes on pub.dev**.

## Project Objective

The goal was to make beautiful, consistent iconography effortless in Flutter apps, to:

- Offer one API for every icon set, colorful and monochrome.
- Keep app size small by importing only the icon sets that are actually used.
- Make icons easy to discover with a searchable online explorer.
- Support every Flutter platform out of the box.

## Key Features

- **100+ icon sets** — Material, Phosphor, Remix, Carbon, Bootstrap, Lucide, Emojione and many more.
- **One simple widget** — `Iconify(Zondicons.airplane)` with color and size control.
- **Colorful icons** — Multi-color sets such as Emojione render with their original colors.
- **Tree-shakable** — Import only the sets you need, so unused icons never reach your build.
- **Icon explorer website** — Browse, search and copy any icon from a dedicated web app.
- **All platforms** — Android, iOS, web, macOS, Windows and Linux.

## Benefits

- **Faster UI work** — Find the right icon in seconds instead of searching multiple libraries.
- **Consistent design** — Mix and match sets without extra setup.
- **Community proven** — Thousands of developers use it in production apps.
